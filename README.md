The objective of this work was to formally specify and verify a **Union-Find** implementation using **Why3**, as part of the Software Verification course at NOVA FCT.

The project focuses on proving the correctness of the `create`, `find`, and `union` operations through preconditions, postconditions, invariants, and termination measures.


- `union_find.mlw` — Why3 implementation and formal specifications.
- `union_find/` — Why3 proof sessions and verification results.
- `report.typ` — Report explaining the specifications and proof decisions.
